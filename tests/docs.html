Simulación de Storage

Web Storage API
crearStorage() → StorageLike
Crea un objeto que simula la API Web Storage para entornos Node.js. Almacena valores como strings dentro de un objeto con Object.create(null) para evitar colisiones con propiedades heredadas.
Retorna
StorageLike
Instancia de storage en memoria, independiente por cada llamada.
Ejemplo
const ls = crearStorage();
ls.setItem('clave', 'valor');
ls.getItem('clave');  // → 'valor'
ls.getItem('otra');   // → null

Réplicas de .html
isReservada(slot: SlotAgenda, citas: Cita[]) → boolean
Determina si una franja de agenda tiene una cita activa asociada. Réplica exacta de isReservada() en medico/pages/gestion-agenda.html.
Parámetros
slot
SlotAgenda
Franja horaria a evaluar.
citas
Cita[]
Lista de citas activas en el sistema.
Retorna
boolean
true si existe una cita con mismo médico, fecha y hora === horaInicio en estado "pendiente" o "confirmada". Las citas canceladas o rechazadas no bloquean la franja.
Ejemplo
const slot  = { medico: 'Dra. X', fecha: '2026-09-01', horaInicio: '09:00', horaFin: '09:30', id: '1' };
const citas = [{ medico: 'Dra. X', fecha: '2026-09-01', hora: '09:00', estado: 'pendiente' }];
isReservada(slot, citas); // → true
esMismoDia(fecha: string, hoy?: Date) → boolean
Comprueba si una fecha ISO corresponde al día actual. La fecha de referencia se inyecta como parámetro para facilitar tests deterministas sin depender del reloj del sistema.
Parámetros
fecha
string
Fecha a evaluar en formato YYYY-MM-DD.
hoy
Date?
Fecha de referencia. Por defecto new Date().
Ejemplo
esMismoDia('2026-06-06', new Date('2026-06-06')); // → true
esMismoDia('2026-01-01', new Date('2026-06-06')); // → false
cambiarEstado(id: string, nuevoEstado: 'confirmada' | 'rechazada' | 'cancelada') → void
Actualiza el estado de una cita en el storage mediante un map inmutable. Solo la cita con el id indicado recibe el nuevo estado; el resto no se modifica.
Parámetros

string
ID de la cita a modificar.
nuevoEstado
string

Implementación
setCitas(getCitas().map(c => c.id === id ? { ...c, estado: nuevoEstado } : c));
confirmarCita({ especialidad, medico, fecha, hora }) → Cita
Crea y persiste una nueva cita. Réplica exacta de confirmarCita() en paciente/pages/cita.html. Lee el nombre del paciente desde sessionStorage['saludya_nombre'] y traduce los value de los <select> HTML a nombres legibles.
Parámetros
especialidad
'medicina_general' | 'dermatologia' | 'pediatria'
Value del select de especialidad.
medico
'dr-paula-garcia' | 'dra-lopez'
Value del select de médico.
fecha
string
Fecha en formato YYYY-MM-DD.
hora
string
Hora en formato HH:mm.
Retorna
Cita
La cita creada, ya persistida en localStorage.
Ejemplo
sessionStorage.setItem('saludya_nombre', 'Ana Gómez');
const cita = confirmarCita({
  especialidad: 'dermatologia',
  medico:       'dr-paula-garcia',
  fecha:        '2026-09-01',
  hora:         '09:00'
});
cita.paciente;     // → 'Ana Gómez'
cita.medico;       // → 'Dra. Paula García'
cita.especialidad; // → 'Dermatología'
cita.estado;       // → 'pendiente'

Framework de tests

Jest-like API
describir(nombre: string, fn: () => void) → void
Define una suite de tests. Equivale al describe() de Jest/Vitest. Registra una nueva Suite en el array global suites, la marca como activa y ejecuta fn síncronamente.
Ejemplo
describir('Mi módulo', () => {
  it('hace algo', () => { ... });
});
it(nombre: string, fn: () => void) → void
Define y ejecuta un caso de test individual. Equivale a it() / test() de Jest. Cualquier excepción lanzada marca el test como fallido.
Ejemplo
it('suma dos números', () => {
  expect(1 + 1).toBe(2);
});
expect(valor: any) → Matcher
Crea un objeto de aserciones sobre un valor. Equivale al expect() de Jest/Vitest. Cada método lanza un Error con mensaje descriptivo si la aserción falla.
Métodos disponibles
.toBe(v)
===
Igualdad estricta.
.toBeTruthy()
!!v === true
El valor es truthy.
.toBeFalsy()
!!v === false
El valor es falsy.
.toBeGreaterThan(n)
v > n
Mayor estricto.
.toHaveProperty(p)
p in v
El objeto posee la propiedad.
Ejemplo
expect(getCitas().length).toBe(1);
expect(resultado).toBeTruthy();
expect(getCitas()[0]).toHaveProperty('id');
